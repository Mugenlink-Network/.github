# Support

Thanks for using Mugenlink Network. Here is the fastest way to get help.

## Where to go

| I want to… | Go here |
|------------|---------|
| Report a bug | Open a **Bug Report** issue in the relevant repo |
| Request a feature | Open a **Feature Request** issue in the relevant repo |
| Report a security vulnerability | **Do not open a public issue** — see [SECURITY.md](SECURITY.md) and email dev@mugenlink-network.me |
| Ask a general question | Email dev@mugenlink-network.me |

## Before opening an issue

- Search existing issues in the repo — it may already be reported.
- Check the repo's `README.md` and `docs/` for setup and usage.
- Include the environment (prod / staging / local) and clear reproduction steps.

| Area | Repo |
